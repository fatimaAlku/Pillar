# Project Description

*E Booklet — max. 100 words*

**Pillar** is a cross-platform study assistant for university students, built with Flutter and Firebase. It helps learners organize subjects, topics, and exam deadlines; build dynamic study plans that adapt as deadlines approach; generate AI quizzes from notes; and track progress to highlight weak areas. Authentication, data, and AI run through Firebase (Auth, Firestore, Storage, and Cloud Functions with an external LLM). One app on iOS, Android, and web turns scattered materials into a clear, responsive path toward exams.
